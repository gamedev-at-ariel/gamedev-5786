אראל סגל-הלוי

למה לבנות לטלפון נייד?

  • כי תעשיית המשחקים בישראל מייצרת (כמעט) רק משחקים לניידים.
  • כי בישראל (כמעט) רק משחקים לניידים מרויחים כסף.

הכנה

  • Unity Hub - Open as Admin - Installs -
    [your Unity version] - Manage - Add Modules -
    Android Build Support [mark all components]
  • File - Build Profiles - Android - Switch Platform.
  • Player Settings - Other Settings - Package Name - com.[company].[game].
  • Player Settings - Other Settings - Scripting Backend - IL2CPP.
  • Player Settings - Other Settings - Target Architectures - ARM64.

התאמת המשחק

  • פקדי מגע במקום מקלדת:
    Binding - TouchScreen - Delta
    Scale Vector2 0.005
  • פקדי מגע במקום עכבר:
    Binding - TouchScreen - Press
    Binding - TouchScreen - Position
  • כיוון: בהתאם למשחק
    Player Settings - Resolution and Presentation - Default Orientation

בנייה והתקנה

  • Build - בונים קובץ עם סיומת apk;
  • מעבירים לנייד (למשל דרך דרופבוקס);
  • פותחים את הקובץ בנייד, מתקינים ומשחקים

פרסום בחנות GooglePlay

תהליך יקר וקשה, אבל חיוני כדי להגיע ללקוחות ולהרויח כסף.
  • פותחים חנות GooglePlay - משלמים 25 דולר;
  • ממלאים כמויות עצומות של טפסים ומחכים לאישור.
  • Build Profiles - Build App Bundle - True (.aab);
  • מעלים קובץ aab לחנות שלכם.
  • ממלאים עוד כמויות עצומות של טפסים על המשחק שלכם.
